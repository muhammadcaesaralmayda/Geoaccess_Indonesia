Pada bagian ini, kita akan membahas tentang operasi dasar dalam Geopandas
 yang meliputi seleksi data, filtering data, dan re-proyeksi CRS. 

-----------------------------------------------------------------------------------------------------------------------------------------------
-----------------------------------------------------------------------------------------------------------------------------------------------

Seleksi Data: Fokus pada pemilihan data berdasarkan label, indeks, atau posisi. Misalnya, memilih kolom tertentu atau baris berdasarkan indeks.
Filtering Data: Fokus pada pemilihan data berdasarkan kondisi atau kriteria tertentu yang diterapkan pada nilai data.

-----------------------------------------------------------------------------------------------------------------------------------------------
-----------------------------------------------------------------------------------------------------------------------------------------------

********************************************** MEMILIH DATA BERDASARKAN KONDISI TERTENTU ***********************************************************

# Filtering dengan kondisi AND
penduduk_besar = adm_bdg[(adm_bdg['WADMKC'] == 'Regol') & (adm_bdg['PENDUDUK'] > 80000)]
penduduk_besar

# Filtering dengan kondisi OR
penduduk_besar = adm_bdg[(adm_bdg['WADMKC'] == 'Regol') | (adm_bdg['PENDUDUK'] > 80000)]
penduduk_besar

# Memuat Data baru
adm_bdg = gpd.read_file("Bandung_DesaAdmin.shp")
permukiman = gpd.read_file("PEMUKIMAN_AR_25K.shp") # data poligon
jalan = gpd.read_file("Jalan.shp") # data garis
pendidikan = gpd.read_file("PENDIDIKAN_PT_25K.shp") # data titik

# Cek CRS Setiap Data
print (adm_bdg.crs)
print(permukiman.crs)
print(jalan.crs)
print(pendidikan.crs)

# Melakukan konversi proyeksi ke EPSG:32748
adm_bdg = adm_bdg.to_crs(epsg=32748)
permukiman = permukiman.to_crs(epsg=32748)
jalan = jalan.to_crs(epsg=32748)
pendidikan = pendidikan.to_crs(epsg=32748)
